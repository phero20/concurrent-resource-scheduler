=========================================
GO TESTING CHEAT SHEET
=========================================

--- Standard Tests ---
1. The Quick Check (Logic only, uses cache)
go test ./...

2. The Detailed Check (Logic only, loud/verbose)
go test -v ./...

3. The Heavy Traffic Check (Logic + Concurrency)
go test -race ./...

4. The Fresh Check (Ignores cached results, forces a fresh run)
go test -count=1 ./...

5. Clear the Test Cache (Doesn't run tests, just deletes the cache)
go clean -testcache

6. Run a Specific Test (Replace TestName with the actual function name)
go test -run TestName ./...

--- Benchmarks ---
7. Run All Benchmarks (Checks execution speed)
go test -bench=. ./...

8. Run All Benchmarks + Check Memory Usage (Highly recommended for performance tuning)
go test -bench=. -benchmem ./...

9. Run Benchmarks AND Standard Tests Together
go test -v -bench=. -benchmem ./...

--- Code Coverage ---
10. Check Test Coverage Percentage (Quick summary)
go test -cover ./...

11. Generate a Test Coverage Profile (Saves the detailed data to a file)
go test -coverprofile=coverage.out ./...

12. View the Coverage in your Web Browser (Highly recommended!)
go tool cover -html=coverage.out
